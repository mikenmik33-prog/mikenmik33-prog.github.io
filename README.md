# hub

Новий проєкт: один застосунок-хаб, у якому зібрані міні-застосунки замість купи окремих — записничок, трекери тощо, під одним дахом і з однією навігацією.

Це чиста початкова точка — старий вміст репозиторію видалено, попередня версія лишилась в історії git.

## Структура (поки що)

```
index.html   Головна — список/меню модулів
modules/      Кожен модуль (записничок, трекер тощо) — окрема папка
```

## План

1. Головний екран-хаб зі списком модулів
2. Перший модуль — записничок
3. Далі — інші модулі за потребою
4. Коли є робочий прототип у вебі — обгорнути в нативний контейнер (Capacitor/Expo) для публікації в App Store
