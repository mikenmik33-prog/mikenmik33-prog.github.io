# mysite

Статичний сайт (HTML/CSS/JS без збірки). Сторінки лежать у корені репозиторію, спільні ресурси — по підпапках.

## Структура

```
index.html            Головна сторінка
movies.html            Список/картки фільмів ("must watch")
statistics.html         Облік прибутку/продажів
university.html        Розділ "university"
accs.html              Каталог кейсів/аксесуарів

css/                    Стилі кожної сторінки
js/                     Скрипти кожної сторінки
audio/                  Звукові ефекти (frog.mp3)
images/posters/         Постери фільмів, використані як резервні копії
backups/                Локальні бекапи даних (не є частиною сайту)
```

HTML-файли залишені в корені, бо на них є прямі посилання (наприклад, `movies.html`, `accs.html`), і сторінки посилаються одна на одну відносними шляхами.

## Зовнішні залежності

Частина посилань у коді веде на каталоги, яких немає в цьому репозиторії — вони мають існувати поруч із сайтом на самому хостингу:

- `../system/` — `movies.html`, `accs.html`, `university.html` посилаються на `../system/index.html` та `../system/page-navigation.js`.
- `../film poster/` — `js/must-watch-data.js` бере звідти постери фільмів.
- `cases_photo/`, `accs_bag/`, `accs/`, `accs_car/`, `staff/` — `js/accsdata.js` бере звідти зображення кейсів і предметів.

Ці шляхи не змінювались під час впорядкування репозиторію, щоб не зламати роботу сайту на хостингу.

## backups/profit-ledger-backup.json

Це експорт особистих фінансових даних (облік купівлі/продажу), не використовується кодом сайту (лише збігається назвою з `suggestedName` при збереженні бекапу в `statistics.js`). Файл, схоже, потрапив у репозиторій випадково — варто перевірити, чи не варто прибрати його з git-історії та додати в `.gitignore`, якщо він не повинен зберігатись публічно.
